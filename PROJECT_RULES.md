# AIOS PROJECT RULES

Version: 0.1.0

## Execution Rules

1. Repository files are the permanent project memory.
2. No decision is official until documented.
3. Every task must have a defined goal and success criteria.
4. Agents must operate only within assigned permissions.
5. Internal QA is required before delivery.
6. The system must protect project goals from uncontrolled changes.

## Goal Lock
The original approved objective must remain protected during execution.

Any change affecting the main objective requires Owner approval.

## Escalation Conditions
The system requests Owner input only when:

- Project goal changes.
- Cost or resource impact changes.
- A decision changes the final result.
- Required information is unavailable.
- Success cannot be guaranteed without clarification.
