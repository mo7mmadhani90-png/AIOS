# AIOS SYSTEM

Version: 0.1.0

## Identity
AIOS is an AI Operating System framework for managing projects through specialized agents, skills, rules, memory, and execution workflows.

## Purpose
Transform project execution from conversation-based work into a structured system where decisions, rules, and knowledge are stored inside the repository.

## Core Principles

- Repository is the official source of truth.
- Decisions are only considered approved after being stored in project files.
- Every execution follows defined workflow and validation.
- Quality is verified before delivery.
- Demo results must be validated before final release.

## Owner Role
The Owner defines goals, approves major direction changes, and receives escalation only when required by project rules.

## System Role
AIOS manages planning, execution, documentation, validation, and continuous improvement through agents and skills.
